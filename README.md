# AI Deep Research Agent

## Project Overview
AI Deep Research Agent is a Python-based application that searches the web, collects information, analyzes research data, and generates AI-powered research reports.

## Technologies Used
- Python
- Streamlit
- Google Gemini API
- Tavily Search API
- Python-dotenv

## Features
- Automated research planning
- Web search integration
- Multiple-source information collection
- Research analysis
- AI-assisted fact checking
- Research report generation
- Report download

## Project Architecture
1. Planner Agent
2. Researcher Agent
3. Analyst Agent
4. Fact Checker
5. Report Generator

## How to Run

Install dependencies:

pip install -r requirements.txt

Run application:

streamlit run app.
